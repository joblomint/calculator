# Calculator

A simple, functional calculator built from scratch with **vanilla HTML, CSS, and JavaScript** — no frameworks, no libraries.

## 🔗 Live Demo

**[https://calc.jkay.my.id/](https://calc.jkay.my.id/)**

Coming soon.

## ✨ Features

- Addition, subtraction, multiplication, division
- Percentage and delete (⌫) buttons
- Graceful handling of division by zero (shows "Error")
- Fixed floating-point precision (0.1 + 0.2 = 0.3, not 0.30000000000000004)
- Clean, modern dark UI with color-coded buttons

## 🛠️ Tech Stack

- HTML5
- CSS3 (Grid layout, custom properties)
- Vanilla JavaScript (ES6+, DOM manipulation, event delegation)
